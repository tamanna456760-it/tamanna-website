IMPORTANT MODEL INFORMATION

Honest about how it works.

This version uses keyword-based retrieval over a small curated knowledge library and imported document text. It is not a trained neural language model and does not generate general-purpose reasoning. A fully independent local AI model would require open model weights, an inference runtime and suitable hardware.
